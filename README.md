# Chicken Little

A calm, colorful companion for a baby's first foods: know what to serve, know what's been tried, feel good about what's next.

## What's here

- `docs/PRD.md` — product requirements
- `docs/content-sources.md` — **government-only** content policy and the sources used so far
- `brand/logo.svg` — the chick-in-an-eggshell logo
- `brand/tokens.json` — palette (Oat, Cocoa, Yolk, Persimmon, Pea, Sky, Plum, Berry), allergen-state colors, type, radii
- `design/` — design canvas source: brand board, Home, Allergen dashboard, Log a food (interactive)

## Brand at a glance

- **Type:** Bricolage Grotesque (headings, numbers) + DM Sans (body)
- **Ground:** warm Oat `#FBF6EE`, Cocoa text `#2B2420`
- **Hero:** Yolk `#FFC93C`
- **Allergen states:** Established = Pea, Introducing = Yolk, Not yet = Oat, Reaction = Berry — always paired with a text label, never color alone
